# Historial de cambios

## 1.0.0 — 2026-09-14

- Reorganización mobile-first de navegación, inicio, elementos, pagos y gestión.
- Inscripción guiada con captura documental y procesamiento asíncrono.
- Control de asistencia mediante sesiones y escaneo QR.
- Control de mensualidades, registro y cancelación auditable de pagos.
- Administración de operadores mediante Supabase Edge Function.
- Esquema canónico de Supabase con RLS, RPC, Storage y validación reproducible.
- Integración documental idempotente con n8n y Google Drive.
- Cobertura unitaria y E2E para móvil y escritorio.
